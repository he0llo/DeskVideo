# DeskVideo

## 软件简介
DeskVideo 是一款运行在 Windows 10 / 11 上的桌面视频播放工具。它能把任意视频以独立小窗口的形式"钉"在桌面上——位于桌面图标之上、其他窗口之下，效果就像给桌面换了一张会动的壁纸，却又完全不打扰你正常使用电脑。
不同于传统动态壁纸软件需要替换整个桌面、占用大量资源，DeskVideo 采用"窗口化播放"的思路：一个视频就是一个窗口，位置、大小、圆角、透明度、音量、边框全部可调，想放哪放哪，想开几个开几个。

## ✨ 特性

- 🎬 支持 `mp4 / avi / mkv / mov / wmv / flv / webm / m4v`
- 🖥️ 三种层级：桌面层 / 普通层 / 顶层
- 🖼️ 三种边框：无边框 / Win11 毛玻璃 / 纯色边框
- 🎨 圆角、透明度、音量可调
- 🧠 遮挡自动降载：被遮挡停止画面，可释放解码器与帧缓存
- 🎭 三态主题：跟随系统 / 浅色 / 深色
- ⌨️ 全局热键（默认 `Ctrl+Alt+Q`）关闭所有视频
- 🚀 开机自启 + 启动自动运行配置
- 🖥️ 桌面预览：拖拽缩放、宽高比锁定、实时调参
